Interactive Lecture Notes — From Vectors to Regularized Regression

$$\mathbf{y} = \mathbf{X}\mathbf{w} + \boldsymbol{\varepsilon}$$

📖 Notation Guide

\(\mathbf{X}\)Design matrix (\(n \times d\)), includes a column of 1s for the bias
\(\mathbf{w}\)Parameter (weight) vector, length \(d\)
\(\mathbf{y}\)Target (response) vector, length \(n\)
\(\hat{\mathbf{y}}\)Predictions: \(\hat{\mathbf{y}} = \mathbf{X}\mathbf{w}\)
\(\mathbf{r}\)Residual vector: \(\mathbf{r} = \mathbf{y} - \hat{\mathbf{y}}\)
\(J(\mathbf{w})\)Loss (cost) function — how wrong the model is
\(\lambda\)Regularization strength
\(\alpha\)Learning rate (step size in gradient descent)
\(n, d\)Number of samples, number of features (incl. bias)
